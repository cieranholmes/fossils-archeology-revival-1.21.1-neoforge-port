# FossilsAndArcheologyRevival

NeoForge 1.21.1 port of the Architectury/1.20.1 mod `FossilsArcheologyRevival` (mod id `fossil`, single-module, no Forge/Fabric split by firm decision).

## Project memory

`.claude/memory/` contains this project's accumulated Claude Code memory, checked into git so it survives across machines (the native auto-memory store normally lives outside the repo, keyed to the local machine's home directory, so it doesn't travel with a clone).

**Read `.claude/memory/MEMORY.md` first** — it's a short index of every memory file with a one-line description of what each covers (migration plan/phases, per-phase progress, known upstream bugs, fixed bugs, feedback on how to judge "done"). Follow its `[title](file.md)` links to the file that's relevant to the current task before assuming anything about project state — several of these note explicitly that they're point-in-time snapshots and should be re-verified against the actual current repo/source state rather than trusted blindly.
